## Description

`gateway/legacy/pricing_v1.py` is a leftover from the kestrel-core era, when the gateway
called the old v1 pricing endpoint directly. It is no longer used. Verified on 2026-06-30:

- Not imported by any module under `gateway/` or `tests/` (grep for `pricing_v1` and
  `legacy`).
- Not referenced by `pyproject.toml`, entry points, or settings.
- No dynamic import (`importlib`, `__import__`) anywhere in the package.
- Not mentioned by any environment variable or config file.

Remove the module and, if it becomes empty, the `legacy/` package.

## Acceptance criteria

1. File deleted; `legacy/` directory removed if empty.
2. `pytest -q` green; application starts (`/api/quote` smoke test).
3. No references in docs.
